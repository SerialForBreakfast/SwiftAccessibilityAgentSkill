## Method and limits

Selected development cases on one model, one first attempt per available condition. Original inputs, returned answers and errors were sealed per pair. The coordinator assessed variable-order masked answers against the developer request and matching rubric. The singleton is identifiable by missingness. For one media-design pair, the first rubric extract included historical case context. The grading copy was narrowed to the observable criteria before those judgments were recorded. The coordinator had seen that context; the pair is not independently blinded to case history. Grade records were frozen before joining the two arms. Grades reflect source review only. No generated code was compiled or executed. Critical flags identify concrete loss of navigation or ordinary operations in an answer and must be compared across the pair. The packet does not measure independent transfer.

Four original sessions returned a startup error and one reservation was interrupted. All five were skipped under the replacement grant. Missing answers have no correctness grade. Raw client account state and logs are excluded from the private bundle. The derived read traces report tool step, returned source excerpt and hash of the original tool record. Full original answer and CLI output are included when captured.
