# Grade the decision and delivery separately

Grade each first answer against its own question before revealing arm, pair or sibling. Keep original text, source, tests, excerpts, hashes and first diagnostics. A revised subject ID never inherits an old verdict.

| Dimension | Values | Evidence |
|---|---|---|
| Accessibility decision | correct / wrong / unresolved | Did the answer make the case-specific decision? Compare against the criterion, valid alternative and concrete counterexample in the controller board. Give an excerpt and user consequence. A missing import does not turn a correct decision into a wrong one. |
| Preservation | preserved / lost / unresolved | Trace ordinary editing, tap, selection, actions or settings through the live control. Flag the particular loss even when another dimension improves. |
| Source builds | pass / fail / not applicable / unavailable | Compile unchanged submitted source in the declared target against the supplied starter. For a justified no-change response report the starter's result separately. A prose design question does not require a build. |
| Submitted tests build | pass / fail / not requested / missing / unavailable | Compile the exact supplied proof against its subject independently. Record real SDK diagnostics; missing fixtures or a bad extractor are harness gaps. Never repair and silently rescore. |
| Proof distinguishes behavior | discriminating / misses defect / rejects valid alternative / unresolved / not requested | Exercise reference, alternative and broken condition where supported. Report what actually ran. A compiling view or a handler test alone does not prove generated semantics or installed gesture wiring. |

**For the direct pairs:** give full decision credit for retaining the working version, including equivalent conditional advice that changes nothing material. Search: reject hiding the editor, not hiding decoration. Cue pad: check the actual single-tap, drag and adjustment registrations independently of handler state. Inspector: the broken member has a test compile defect, not a runtime state defect; do not change the production enum solely to satisfy one test syntax. Preserve the working case checks. Do not require UI testing.

**For a future comparison:** same exact subject bytes, tools, model and settings across arms. Report failures rescued, new losses, preserved successes, persistent failures and unknowns per question and decision family. On direct pairs also report both variants correct. Report decision gains separately from source/test build gains. Reserve uninspected families for transfer. No session count or spend authorized by this freeze.
