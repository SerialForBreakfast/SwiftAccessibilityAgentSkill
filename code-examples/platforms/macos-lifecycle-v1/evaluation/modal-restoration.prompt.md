In our AppKit/macOS app, closing a modal should request a return to the original button, or a fallback if that button is no longer eligible in the owning view. The controls may be removed, hidden or disabled while the modal is open. A new modal can replace an older one, and cancellation or duplicate completion must not disturb the new flow. Implement a small coordinator that runs only after dismissal completes, handles a request that starts another modal, and can be unit tested without driving the UI. Target macOS 26.0.
