In our AppKit/macOS app, a screen needs the current Reduce Motion, Reduce Transparency and increased-contrast settings when it starts, then updates when those settings change. It may stop and restart while an update is already queued. Repeated identical values should not trigger extra rendering. Implement a small observer with correct platform notification registration, owned cleanup and unit tests using injected settings and scheduling. Target macOS 26.0; do not change the machine's settings.
