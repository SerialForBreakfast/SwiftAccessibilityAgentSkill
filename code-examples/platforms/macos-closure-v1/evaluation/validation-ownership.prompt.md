Our AppKit macOS form has editable name and email fields. Validation is supplied as a callback-based service that takes a snapshot of both strings and eventually returns a dictionary of field IDs to nonempty error messages; an empty dictionary means valid. The callback runs on the main actor but may run immediately, twice, or out of order. A user can edit, cancel, or submit again before it returns. Implement ownership of the pending state and results without replacing the existing fields or losing entered text. Request the first invalid field in name-then-email order, and pass successful snapshots to our save callback, which can itself start another validation. Treat unknown field IDs or empty error messages as a service error. Target macOS 26; include deterministic unit tests without networking or UI automation.
