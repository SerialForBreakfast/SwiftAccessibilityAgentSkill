Our tvOS app uses AVPlayer. We asynchronously load a short description of its current AVPlayerItem through an injected callback on the main actor. Items can be replaced externally, the same item can be inspected again, and results can arrive late or twice. Implement a small owner for loading, success, error, cancellation and no-item states. It must not apply results to a different current item or alter playback preferences. The callback may outlive the owner. Include deterministic unit tests using synthetic player items; no network or UI automation. Target tvOS 26.
