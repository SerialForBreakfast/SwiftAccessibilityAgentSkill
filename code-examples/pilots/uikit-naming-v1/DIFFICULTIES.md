## Design Difficulties Addressed Before Execution

- Native button-role getters were unreliable evidence in the prior tranche. This
  example deliberately tests explicit configuration rather than asserting defaults.
- Resetting a UILabel label override may expose a derived text value. The oracle
  rejects the stale override instead of assuming the getter must return nil.
- Repeated visible titles are not inherently invalid. The task supplies a concrete
  need for item context; the rubric accepts equivalent contextual solutions.
- Reconfiguration must not accumulate callbacks. Register handlers once and replace
  the current closures; tests check old-handler suppression and exactly one current call.
- A resilience test that resets externally altered flags is useful for this owned
  fixture but is not an unspoken universal requirement on model answers.

These are anticipated pitfalls informed by prior evidence, not new observed failures.
No failed code snippet is invented for them. Exact intentional negative changes are
preserved in `NegativeFixtures/` and the mutation diff artifact. If native execution
reveals an unexpected failure, preserve revision1 and its diagnostics before editing.
