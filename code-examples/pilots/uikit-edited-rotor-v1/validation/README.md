# Edited Rotor Native Evidence

[Sanitized records](revision-1.json) bind the manifest, exact source/test inputs,
selected test identities, environment and original private record/log hashes.
The positive suite contains twelve distinct methods. Five manufactured variants
test UTF16 offsets, overlap policy, first-search restart, old callback invalidation
and out-of-band text changes. These are not independent model questions.

Environment: Xcode27.0 build27A266a, Swift6.4, SDK27.0 build24A430, arm64,
deployment26.0 and actual iOS26.5 build23F77 for unit runs. Compile-only evidence
has no runtime. Local work date is November5,2026; raw UTC dates are November6.

Results establish direct callback behavior, match-range policy and native text-range
compatibility. They do not establish actual rotor gestures, speech, focus delivery,
localized search quality or stable annotation identity across edits. Ordinary text
configuration is asserted separately from the optional rotor path.

Raw process logs and xcresult bundles remain private and immutable. Public excerpts
remove private-path aliases and object addresses while retaining assertion identities
and hashes. Independent case review and model evaluation remain pending.
