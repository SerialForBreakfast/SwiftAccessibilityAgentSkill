# Native structure and form parity delta

This advances the [previous media queue](../platform-media-v1/COVERAGE.md) while
preserving its historical dispositions. Parity is behavioral, not equal test counts.

| Capability | Newly asserted Mac subset | Newly asserted TV subset | Still open |
| --- | --- | --- | --- |
| Form recovery | Visible errors, retained input, help reset, ordinary action, disabled/reentrant submission | Same policy through UIKit controls and editingChanged | Multiple-field error routing, async validation cancellation and production layout |
| Hierarchy | NSOutlineView root/child topology, expandable state, per-column values | Custom shelf heading/button hierarchy and configured order | Richer native collection/outline row-view semantics |
| Identity and updates | Stable node objects, atomic global duplicate rejection, surviving expansion/selection | Section-qualified identity, atomic duplicate rejection and removal/reorder | More complex update transactions and framework reuse contracts |
| Stale action/data protection | Removed nodes cannot supply children | Old-generation and detached current buttons reject actions | Cross-controller handoffs and broader lifecycle cases |
| Text/rotors | Platform-specific audit pending | Applicable API audit pending | No inferred iOS equivalence |
| Media lifecycle | Earlier metadata/selection/inspection evidence retained | Earlier metadata/selection/inspection evidence retained | Item replacement/cancellation and format-specific contracts |
| SwiftUI | Deferred | Deferred | No expansion |

The new form policy is shared but tested through separate platform entry points.
The outline and shelf models are intentionally distinct. No claim is made that
these examples close every clause of macOS m-006 or tvOS t-004, or that storing a
container array proves a VoiceOver traversal order.
