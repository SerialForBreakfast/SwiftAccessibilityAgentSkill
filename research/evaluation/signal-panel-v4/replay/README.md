## Evidence boundaries

The initial 46 original-contract dispositions: 15 unit passes, 5 unit failures, 13 compile-only, 5 build-for-testing only, 5 subject build failures, 2 oracle build failures, 1 source-only. Separately, the first submitted-proof lane returned 22 unit passes, 1 unit failure, 8 test build failures, 7 with no executable proof, 5 blocked by the first subject build, 1 undiscovered check, 1 source-only and 1 offline build-only. These are first-host counts, not final defect totals. A test using an unavailable Bundle.module resource is a fixture gap unless a separate diagnostic establishes a source defect.

Across the initial and focused hosts there are 105 recorded native build/test invocations, not 105 unique behaviors. Xcode 27.0 (27A266a), SDKs 27.0, deployment 26.0; iOS/tvOS simulator 26.5 and macOS 27.0. No UI tests, external media fetches, model calls, new holdouts, or grade rewrites.

**First failures retained.** Two observer contracts lacked the original PreferenceHarness; both passed after restoring it. The first iOS v4 media subject omitted the original unchanged FormMediaState dependency in staging; adding the starter prefix compiled it. The initial tvOS media probe omitted the view's explicit load call. Neither staging issue counts as a new model defect. The original v2 wrapper assembly omitted a submitted identifier extension; the integrated result, not the first build failure, is the relevant comparison. Native asset-backed contrasts stage private movies under the project and replace temporary-file fixture plumbing, not answer behavior.

Run `python3 -B report.py --check` on the evidence host to validate the recorded snapshots and receipts. Private artifacts reside in the named evals/results/persistent-replay batches. To stage a fresh run, prepare.py prints a new batch name; native.py takes that name. chapter.py, focused.py, integrate.py, contrasts.py, registration_host.py and media_binding.py stage the documented separate follow-ups. They do not overwrite original cells. Source selection and host composition are explicit: some answers need a declaration splice or unchanged starter, and optional alternatives are not silently counted as the primary response.
