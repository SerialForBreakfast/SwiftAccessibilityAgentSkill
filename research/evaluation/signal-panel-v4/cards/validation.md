Which path changes the field? If both the native control and a cancellation helper can edit it, editing only through the helper cannot verify a native edit during validation. Invalidate through the actual edit path or compare current input with the submitted snapshot when the reply arrives.

Distinguish obsolete input from obsolete ownership. If A still owns the pending state after an edit, retire A without accepting its old input or stranding Submit. If B now owns it, A must not clear B's feedback or busy state. Where a check is requested, mutate the live field, deliver A, then finish a current submission and inspect the accepted input and eligibility.

For queued observers, change the value before draining a retired delivery so deduplication cannot hide a stale update; exercise the current subscription too. A duplicate progress callback after completion is different from a later task's first completion.
