# Single return format
return.json is a JSON object: job, packetSHA256, status (complete/partial/blocked), stopReason, report, runLedger, cells, and, if grades exist, gradeFreeze and maskMap. Each artifact reference is {"path":"relative/member","sha256":"hex digest"}. Use actual files, not worker-local paths. runLedger includes reservation, timestamps, billed spend and approved configuration. report includes the paired tables, quoted evidence and limitations specified in HANDOFF.md.

One cell per schedule entry, even if never started: id, arm, state, attempts. Unattempted: zero attempts and reason. Error/answered: one attempt, questionSHA256, skillSHA256, request, receipt, transport, usage and trace artifacts. Record unavailable telemetry explicitly inside the corresponding artifact. Error adds error artifact. Answered adds answer artifact, mask, boolean critical, graderInput, graderOutput and grade. A partial return may explicitly mark grade null with reason. grade maps primary, preservation, integration, verification, rework and whole to {verdict,reason,excerpt}; use original verbatim answer excerpts for pass/fail. If content is missing, quote the complete relevant implementation path and explain the omission. Keep original input/output before masking; freeze mapping separately before analysis. Provide reports that distinguish observed reads from reported citations.

Run the included checker against the actual held zip, externally supplied SHA and final return zip. It validates structure, case accounting, hashes and excerpt membership. It cannot attest that the worker used the approved subscription or that a grade is sound: controller review of signed/available transport records, actual input and masking remains necessary. A missing evidence lane must be disclosed, not simulated.
