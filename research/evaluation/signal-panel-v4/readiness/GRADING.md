# Masked evaluation contract
Grade each observable requested in the exact question, against its starter. Accept equivalent implementations. If a source example or suggested contrast imposes an incidental requirement, the question wins. Do not require every example in a family contrast. Never require the sample class name, storage mechanism, or particular assertion syntax.

Record primary correctness, preservation of ordinary actions/navigation, integration, verification, rework and whole separately as pass/fail/unknown/na. Fail rework only for concrete unnecessary work, not a harmless equivalent. Missing input, unbindable XCTest or tool failure is not a code defect. A source-supported answer or check is not an executed test. Specify the evidence level. Report a newly lost ordinary action or navigation path separately even if the aggregate improves.

Verification scope is sealed per case. For only-if-fix-needed, decide whether the supplied code actually needs a fix BEFORE considering the author's conclusion. For no-added-proof-requirement use na; for describe-check, accept a concrete plan, not a claimed execution. For focused-check accept any sufficient discriminating witness. For supply-tests require the requested tests. Distinguish disappearance from attached ineligibility; helper cancellation from native edits; dismissal request from completion. Do not reject different correct solutions that demonstrate the same observable. A source-judged failure and a native interface gap can coexist.

Whole pass requires all applicable requested outcomes; a concrete material miss is fail, otherwise unresolved material evidence is unknown. Do not fold identity, routing, tool use, or token cost into answer quality. Mask identity, routing and condition-specific file paths in copies only; preserve code and evidence. If arm would be obvious, mark masking limitation. Freeze grades before revealing arms. For each dimension retain excerpt, reason, and decisive path; for omissions retain full relevant path. Keep native proof and implementation lanes separate. Source grading is permitted; new inference for grading, UI or native runs are not included in this proposed job.
