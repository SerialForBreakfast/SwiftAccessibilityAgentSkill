The runner typechecks the exact three Swift fences on installed simulator SDKs, then executes the edit declaration with a host test driver. The host substitute changes only the unused UIKit import to Foundation. Native first diagnostic: the original host driver's top-level calls were not main-actor isolated. The repair puts the driver, not the subject, on the main actor. First source and diagnostic remain under `evals/results/decision-controls-first/`.
