# Masked scoring, revision 2

Use the sealed developer request and its supplied starter as the contract. The controller carries the observable criterion, accepted alternatives or the original source rubric. Do not require a preferred implementation. A direct-detach solution need not handle reparenting unless requested. For a missing requirement or conflicting oracle, record inconclusive with the conflict; do not silently strengthen the task.

Grade primary behavior, preservation of ordinary behavior, integration into the supplied path, and requested verification separately: pass, fail, inconclusive or not applicable. Record unnecessary rework separately (harmless equivalent / avoidable change / damaging change). Do not turn harmless equivalent syntax into a failure. Explanation-only questions do not require executable tests. For requested checks, absent setup or a circular assertion does not establish a result. A check of the wrong handler can fail verification while the production change passes primary. Whole pass requires all applicable requested outcomes, without material collateral loss. Whole fail requires an evidenced material miss; otherwise unresolved evidence is inconclusive.

Grade first answers masked and freeze them before unmasking. Use unchanged code and only the matching approved compile/unit contract when applicable. Record gating, oracle or environment failures separately. Passing a helper cannot establish interaction delivery. A newly lost ordinary action or navigation path is a blocker even if net gains are positive. Report safe alternatives, developer consequence, decisive excerpts from both answers and what was and was not executed.

Report scheduled and completed denominators, whole and component transitions by platform/framework and family, matched fixture outcomes, inconclusives and critical regressions. Count distinct rescues by decision family, not executions or variants. Keep discovery rates, actual reads, token usage and latency separate from answer quality. Whole-family transfer remains unmeasured here.
