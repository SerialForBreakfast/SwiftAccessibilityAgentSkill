The task was interpreted with the existing unit-only, platform-specific parity,
zero-spend and immutable released-skill/baseline boundaries. Four independent
questions and separate grading rubrics are captured byte-for-byte with hashes in
[prompt-records.json](prompt-records.json). They are drafts; no subject model has
answered them. Empty answer fields mean not run, not missing successful responses.

Available authoring outputs are the Swift sources, test sources, manifests,
negative controls, source-audit corrections and research analysis in this batch.

summary and results. A durable private archive retains those original tool inputs
and outputs; the public result index records hashes and sanitized failures.

The original Mac implementation/tests/manifest and first TV mutant/manifest are
preserved separately. See DIFFICULTIES.md for chronology and classification.
This is local authoring evidence, not independent prompt execution or a model
comparison. There were no model calls, judge prompts or authorized repair runs
against independent answers.

Capture limitation: the full active-session provider transcript, system context,
all intermediate tool messages and sampling/model metadata are not available as
an export here. This visible request plus file/native artifacts is a partial
capture, not a fabricated complete transcript. The prior private session capture
and original nine-case index are unchanged. Future worker runs must retain complete
rendered subject inputs, first outputs, tool traces and separate analysis.
