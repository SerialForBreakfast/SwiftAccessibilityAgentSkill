## Append-Only Execution History

Operational limitations were kept separate from subject defects: sandboxed process
listing returned `operation not permitted: ps`, so monitoring used the runner's lock,
receipts and progress log. The web reader rejected Apple's Markdown content type;
the same official URLs were fetched as read-only text and hashed. Neither condition
is an accessibility defect or a reason to change a gold answer. A documentation
patch with a mismatched context was rejected without changing a file, then corrected.

Each campaign freezes input contents and environment before native execution.
Original logs, input snapshots and result receipts live in the private execution
root; public records carry hashes and sanitized outcomes. New repair revisions
must link their parent attempt and classify subject, oracle or harness defects.
Allow at most two repair attempts per contract. Never replace a first failure with
the final pass or count a build/infrastructure failure as a useful mutant rejection.
