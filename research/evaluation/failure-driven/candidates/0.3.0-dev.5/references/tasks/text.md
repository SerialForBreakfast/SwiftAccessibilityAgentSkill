# Text scaling and non-color state

Use semantic/scalable font configuration with live update integration, multiline text and flexible layout. Wrapping alone does not scale a fixed font; a preferred font alone does not establish later updates. Preserve the existing Pay/action control, typography and callback rather than replacing it unnecessarily. A permanent vertical layout or another justified arrangement can be valid; do not mandate an adaptive-axis implementation. Keep selected/error state understandable without color alone. TV26 text configuration is not TV27 system Larger Text support.

Use only for this concern. Apply Apple source/SDK contracts to the actual target; examples and application policies are not universal platform guarantees.

First identify what text-scaling behavior is actually available on this platform and deployment target. When primary evidence is missing, give a bounded layout recommendation and request or retrieve that evidence before asserting an API contract.
