# Presentation and preferences

Resolve a current return anchor or fallback at dismissal completion, not before dismissal or from a stale captured view. Separate eligibility and request timing from delivered focus. Ignore obsolete presentation callbacks; consume the current session before reentrant external work. Keep ordinary Close wiring and preserve preexisting background state; a modal-only design can be valid without mutating hidden flags. Final application state must update even when animation is reduced; apply content before optional animation. Stop observers and invalidate queued callbacks across teardown/restart.

Use only for this concern. Apply Apple source/SDK contracts to the actual target; examples and application policies are not universal platform guarantees.

Evaluate dismissal, cancellation, replacement and duplicate completion as separate transitions. Resolve fallback ownership deliberately when the original item disappears; a recorded request is not evidence that assistive technology delivered focus.
