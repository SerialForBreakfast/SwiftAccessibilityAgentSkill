# Names, roles and valid native controls

Use native controls before overrides. An accessibility identifier is not a spoken name. Fix an evidenced defect, not an absent modifier. Keep icon-only names meaningful and neighboring actions distinguishable. Preserve valid Toggle/Button bindings and appearance; a correct no-change answer is useful. Follow the exact native owner at a bridge; UIKit traits, AppKit roles and SwiftUI modifiers are not interchangeable.

Use only for this concern. Apply Apple source/SDK contracts to the actual target; examples and application policies are not universal platform guarantees.

Separate the evidence of a visible name from inferred defaults. Do not prescribe SwiftUI modifiers to UIKit/AppKit or native trait defaults to SwiftUI. If the supplied implementation is valid, say so without manufacturing a patch.
