## Offline development difficulties

The first metadata-finalization script used a JavaScript colon where assignment
was required. It did not write the new metadata; the hash test correctly caught the
stale subject pin. After repair, another over-broad oracle rejected any path containing
"evaluation", including the candidate's legitimate research asset location. It was
corrected to require the exact candidate task-note and primary-guideline paths.
These are authoring/controller errors, not accessibility defects or model results.
Original local test logs are not represented as complete provider transcripts.

## Deliberate source gaps

AppKit text/media and UIKit/tvOS text need more specific primary mappings. They
return requires-primary-source with zero delivered context, rather than selecting
contrast/role guidance as a substitute. Existing native examples remain available
in the companion but are not proof that an unrelated primary source is applicable.
The three gaps are visible, not silently treated as routing success.
