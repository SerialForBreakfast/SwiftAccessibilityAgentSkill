# Containers, landmarks and rotor navigation

Group descriptive fragments without hiding independent controls. Keep ordinary linear task completion available to people unfamiliar with rotor shortcuts. Use headings for real landmarks, not every row. Stable IDs, reorder/removal and stale action ownership are application contracts to preserve. Native children/order properties and SwiftUI modifier compilation do not establish generated-tree structure or actual rotor navigation. For text ranges, match the framework coordinate system and whole-character boundaries; invalidate cached ranges after edits.

Use only for this concern. Apply Apple source/SDK contracts to the actual target; examples and application policies are not universal platform guarantees.
