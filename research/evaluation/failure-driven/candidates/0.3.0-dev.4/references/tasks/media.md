# Media evidence and control preservation

Preserve native playback controls, player identity, user choices and ordinary actions. Distinguish missing, loading, failed and successfully empty metadata according to the supplied loader contract. Keep full captions separate from forced-only tracks and content description from descriptive-track metadata. Synthetic preference selection is not applying AVMediaSelection, extracting a real asset or rendering captions. Inspect stream details only when relevant; debug metadata need not become verbose spoken output. Verify target/device/language availability before newer generation/style APIs.

Use only for this concern. Apply Apple source/SDK contracts to the actual target; examples and application policies are not universal platform guarantees.
