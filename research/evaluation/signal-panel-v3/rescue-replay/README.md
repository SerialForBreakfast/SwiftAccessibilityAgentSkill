## Evidence boundaries

18 private cell dispositions; 16 attempted production build/test lanes (including two compile-only media lanes); 2 additional adapter-repair executions; 14 separate submitted-proof executions. The 14 proof runs comprise **9 installed-or-unaided passes** and **5 failures** (see per-arm ledger). First logs are authoritative even where a process prints a secondary harness message. The unaided working-row trap is identified in the evidence projection separately from the generic first parser status.

Each original answer and question is stored byte-for-byte. The runner selects final implementation fences, applies the stated patch to the original starter, or leaves the starter unchanged for a no-change answer. Unrelated explanation and optional alternative implementations are not silently combined. Subject code was not repaired. Named XCTest method bodies come from the paths and selectors bound by the frozen controller. Proofs run separately with framework imports, a matching testable module name, and an XCTest host for free functions. For the two AppKit rows, an additional probe checks the current ID after ordinary button dispatch; it does not assert VoiceOver behavior.

The first tvOS harness truncated helper signatures at default closure arguments, causing identical syntax errors in the **test target**. The repair scans through the parameter list before extracting the body. Both repaired attempts use identical implementation hashes to their respective first attempts. No subject retry. Media compiler errors are **not** harness gaps; a missing native oracle is. Sources were compiled with Xcode 27.0 (27A266a); exact SDK, deployment target and runtime are recorded per cell.

## Candidate decision

Adopt the strategy's distinction between discovery, behavior and verification. The additive successor has a when-to-use description and [five trigger/near-miss pairs](trigger-fixtures.json), not a claim of improved triggering. Keep capture, stale rejection and reentrant retirement together. Keep citations outside compilable declarations. Check the requested category settings independently of a sample factory's defaults. Check ordinary button dispatch via its observable recipient; do not infer delivery from a press Boolean. No mandatory examples or new cards. Card reads remain observational, not a causal basis for ranking or dropping rules. This tranche authorizes neither a fixed repeat budget nor a new model run.
