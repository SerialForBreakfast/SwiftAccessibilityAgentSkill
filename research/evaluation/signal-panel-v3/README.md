# Signal v3: lifecycle callbacks and native selection

Research successor to signal-v2, not a release or a worker job. [Candidate](candidate.zip) · [native evidence](evidence.json) · [case-level reads](trace-review.json) · [contracts and grading](RUBRIC.md).

**Why change content vs discovery?** On the 10 installed answers in these four related families, the UIKit reopen case and two of three SwiftUI sheet cases had corroborated reads of the return card, including both candidate-only critical flags. Both actual-player-write failures had reads of the media card. More routing alone does not address those observations. Add the missing contrast and check at the decision point. None of the four wrapper cases had corroborated body or action-card reads; their primary outcomes included two gains, one preservation and one regression. Improve the discovery description and route cue as a hypothesis; do not attribute unread guidance or its absence to an individual outcome. These are associations on first attempts, not causal rule-level scores.

**Four native contracts.** The UIKit test rejects a final hidden background and verifies ordinary Apply and one final target. The SwiftUI test drives the no-argument dismissal closures used by the modifier; the stale one cannot consume its replacement. The wrapper test invokes a retained native accessibility action and dispatches both current ordinary controls. The media test starts from no captions, changes a real AVPlayerItem through the picker binding, reads the native selection, exercises old/current Off, and checks that described audio stays selected. It uses a synthetic local MOV, not network streaming. The first three run on iOS; the last runs on iOS and tvOS. This tests configuration, callback execution and framework state, not delivered VoiceOver focus, rendered navigation or playback quality.

**Distinguish the example from the incident.** Native tests exercise maintained examples, not rewritten copies of the graded answers. Three use existing sources unchanged; the presentation modifier is new. The reference solution retires A before opening B; the lifetime alternatives in alternatives.py are staged only for qualification. Each intentional mutant changes a separate source: wrong final background flag, obsolete callback accepted, lost registration guard, or no write to the native group. Tests must fail at their named assertion rather than merely fail compilation. Mutants represent mechanisms and are not exact transcripts. Raw staged sources, first logs and xcresults remain under ignored evals/results/signal-v3-native. Public evidence carries their digests.

**Reproduce offline:** from this directory run `python3 -B run.py iOS positive`, then replace positive with alternative and mutant. Repeat on tvOS. Requires Xcode and the named booted 26.5 unit simulators; each invocation creates a new immutable attempt. Run `python3 -B evidence.py --check` on the evidence host, or `python3 -B build.py --check` to reproduce the candidate from the sealed parent. Add `--traces` to verify the trace projection from the hash-pinned private return. Use `python3 -B evaluation.py sheet` (or panel/wrapper/media-ios/media-tvos) for the complete original subject without controller notes. All five subjects remain development cases. Do not infer independent review, skill discovery, or model improvement from native tests.
