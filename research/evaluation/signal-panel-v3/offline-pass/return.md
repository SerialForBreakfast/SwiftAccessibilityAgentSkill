Restore only when needed, on completed dismissal, not the close request or cancellation. Capture the origin independently of presented content: clearing that content is not evidence the origin disappeared. Resolve eligibility at completion. Consume only the matching request before calling reentrant code.

For overlapping UIKit panels, transfer the original background accessibility snapshot or restore it before taking the next snapshot. Finish A late, then B twice: B restores the original state once (also when initially hidden). Keep ordinary controls attached and wired.

Bind SwiftUI onDismiss to its presentation or serialize presentations; reading the current ticket in an old callback gives A the identity of B. Drive the actual no-argument callback, not a helper given the correct ticket. In AppKit check the original window and the result of makeFirstResponder; on refusal try the requested eligible fallback. A focus request does not prove delivered focus.
